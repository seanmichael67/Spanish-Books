# Weekly book-club emails

Paste each file into a new **Broadcast** in Resend (Broadcasts → Create → HTML), send it to the
book club audience, one a week. `{{{RESEND_UNSUBSCRIBE_URL}}}` is filled in by Resend.

| File | Subject line |
|---|---|
| `week-1.html` | Start the way Spanish children learn to read |
| `week-2.html` | A story to read three times |
| `week-3.html` | A colour hunt in your house |
| `week-4.html` | What does the cow say in Spanish? |
